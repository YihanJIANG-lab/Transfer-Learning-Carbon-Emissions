# Transfer Learning for Corporate Carbon Emissions Prediction

This repository contains the code and results for a research project that applies transfer learning to predict corporate carbon emissions across countries. By leveraging data from regions with abundant labeled samples, the models improve emission predictions in countries where labeled data is scarce.

## Overview

Accurate corporate carbon disclosure is essential for climate policy, yet many countries lack sufficient firm-level emissions data. This project addresses the data scarcity problem by training models on global or developed-country data and transferring that knowledge to individual target countries.

**Emission scopes predicted:**
- Scope 1 (direct emissions)
- Scope 2 (purchased energy)
- Scope 3 Upstream
- Scope 3 Production
- Scope 3 Downstream
- Scope Total

**Transfer learning strategies evaluated:**
| Experiment | Description |
|------------|-------------|
| A | Country self-modeling (train/test on single-country data) |
| B | Global baseline (train on all countries except target) |
| B_dev | Developed-countries baseline |
| C / C_dev | MLP with global / developed-country pretraining → fine-tuning |
| D_lora / D_lora_dev | FT-Transformer + LoRA fine-tuning |
| D_full / D_full_dev | FT-Transformer full parameter fine-tuning |
| CT | Cross-Time Contrastive Learning (self-supervised pretraining) |

- [PyTorch](https://pytorch.org/) (with CUDA support recommended for GPU experiments)
- [LightGBM](https://lightgbm.readthedocs.io/)
- [Optuna](https://optuna.org/) (hyperparameter tuning)
- pandas, numpy, scikit-learn, scipy
- h5py (HDF5 data I/O)
- matplotlib, seaborn (visualization)

Install dependencies:

```bash
pip install torch lightgbm optuna pandas numpy scikit-learn scipy h5py matplotlib seaborn
```

**GPU experiments** (notebooks `03b` and `04`) require an NVIDIA GPU. The experiments were tested on an NVIDIA A800-SXM4-80GB. Multi-GPU setups are supported via the worker modules.

## Usage

Run the notebooks in order:

1. **`01_Data_Cleaning.ipynb`** — Load the raw Trucost-Compustat dataset, apply log(x+1) transformations to the six emission scope targets, and save the cleaned data to `data/Emi-ready.h5`.

2. **`02_Feature_Engineering.ipynb`** — Perform missing-value filtering, correlation pruning, outlier winsorization, and LightGBM-based top-100 feature selection. Outputs `data/processed_feature_data.h5`.

3. **`03a_CPU_AB_Experiments.ipynb`** — Run LightGBM-based experiments A and B on CPU. Covers 55 countries with at least 50 labeled samples.

4. **`03b_GPU_CD_Experiments.ipynb`** — Run MLP and FT-Transformer experiments (C and D variants) on GPU. Results are saved per country with checkpointing for resumable runs.

5. **`04_CT_CCTL_EMIT.ipynb`** — Run Cross-Time Contrastive Learning pretraining followed by supervised fine-tuning. Supports multi-seed evaluation for robust reporting.

6. **`05_Results_Analysis.ipynb`** — Aggregate all results and produce summary tables and heatmaps (saved to `results/`).

## Key Technical Features

- **Multi-target regression**: Predicts all 6 emission scopes simultaneously with NaN-aware loss
- **Parameter-efficient fine-tuning**: LoRA adaptation for FT-Transformer
- **Self-supervised pretraining**: Cross-time contrastive learning using firm-year pairs as positives
- **Robust evaluation**: Time-series train/test splits, multi-seed reporting (mean ± std)
- **Scalable**: Multi-GPU distributed training with checkpoint-based resumption
- **Large-scale data**: ~199K labeled firm-year observations across 150+ countries/regions
